# AlperEnesErsu.net

Kişisel portföy sitem: hakkımda, deneyim, projeler, sertifikalar ve iletişim — modern, animasyonlu tek sayfa.

> 🚧 Aktif geliştirme aşamasında — her gün küçük adımlarla ilerliyor.

## Teknolojiler

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** — animasyonlar
- **Netlify** — yayın

## Bölümler

- Hero / açılış animasyonu
- Hakkımda + odak alanı
- Deneyim
- Projeler (interaktif önizleme + kategori filtresi)
- Sertifikalar
- İletişim & sosyal medya

## Geliştirme

```bash
npm install
npm run dev   # http://localhost:3000
```

## Yol Haritası

Proje, sınav dönemim boyunca günlük küçük PR'larla geliştiriliyor (6–17 Haziran). Her PR sitenin somut bir parçasını ekliyor.
